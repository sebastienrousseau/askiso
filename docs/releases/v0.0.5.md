## Highlights ⭐️

* **Three security advisories resolved**: AskISO now requires Go 1.26.10 and golang.org/x/net v0.62.0, which fix what govulncheck reported against Go 1.26.9 and x/net v0.60.0.
* **Files it writes are private to you**: an imported catalogue, a message translated with `--out`, and the directories holding them are no longer readable by other users on the same machine.
* **A clean static security scan**: gosec reports 0 issues, down from 46, every one fixed in the code.
* **A clearer search button**: its accessible name now includes the keyboard shortcut, and the site builds with ssg 0.0.70.
