## Highlights ⭐️

* **Signed and notarised on macOS**: every macOS binary carries a Developer ID signature and Apple's notarisation, so Gatekeeper runs it without a prompt. The release checks this on a Mac before it is done.
* **Homebrew and Scoop**: `brew install --cask sebastienrousseau/tap/askiso` on macOS and Linux, and `scoop install askiso` on Windows, both installing all four binaries.
* **Provenance for every download**: each archive and package now has its own build attestation, so `gh attestation verify <archive>` works as the README shows.
* **One way in from other languages**: the C shared library is removed, along with the FFI entry point that accepted a caller's catalogue path. `askiso-server` is the route for code not written in Go.
