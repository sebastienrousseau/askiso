## Highlights ⭐️

* **ISO 20022 reference in three places**: `askiso` answers questions about messages in the terminal (CLI and TUI), `askiso-lsp` brings the same answers to an editor, and `askiso-mcp` to an AI assistant.
* **The askiso.io website**: built with ssg, with a generated page for every ISO 20022 message definition, a playground, a workspace with SARIF and evidence-pack exports, and the November 2026 structured address page.
* **Signed, verifiable releases**: binaries for Linux, macOS and Windows with an SBOM per archive and a checksum file signed keylessly with Sigstore.
