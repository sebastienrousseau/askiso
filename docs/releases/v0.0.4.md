## Highlights ⭐️

* **Go 1.26.9**: the toolchain and the CI matrix move to the patch release that fixes nine security bugs govulncheck found in net/http and html/template.
* **golang.org/x/net v0.60.0**: the networking module moves up alongside the toolchain, and the build and verification workflows run on the same Go release on Linux, macOS and Windows.
