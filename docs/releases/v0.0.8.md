## Highlights ⭐️

* **macOS signatures that verify**: 0.0.7's macOS binaries were notarised, but their signature named the wrong certificate as its root, so `codesign --verify --strict` rejected them. This release signs with the Developer ID certificate alone, and its binaries pass.
* **A release check that catches it**: the release now confirms on a Mac that every binary satisfies its own signature requirement and that Apple has notarised it, using checks that work for command-line tools.
