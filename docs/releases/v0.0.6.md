## Highlights ⭐️

* **Release pages you can rely on**: every release is titled `askiso <version>` and lists its highlights, its pull requests and the SHA-256 of every download, written by the release workflow and read back before it finishes.
* **Verification that works**: the README's command now checks the Sigstore bundle releases actually ship, and shows how to check the build provenance with `gh attestation verify`.
* **A README you can find things in**: one layout shared with the other projects, a rendered demo, and a changelog, an architecture guide and a code of conduct beside it.
* **Gates that keep it that way**: CI now checks the README layout, the Markdown, and that every exported identifier in the Go API is documented, and the website builds with ssg 0.0.71.
