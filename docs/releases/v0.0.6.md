## Highlights ⭐️

* **AskISO from any language**: `askiso-server` serves lint, validate, translate and lookup over HTTP, and `cmd/askiso-cabi` builds the same operations as a C shared library, both speaking one JSON contract (`askiso-abi/v1`). The server reads only the catalogue its operator chooses and keeps host paths out of its responses.
* **SR2027 address readiness**: `askiso audit` scores how many messages carry structured, hybrid or unstructured postal addresses, as text, JSON or HTML.
* **Go 1.26.11**: the new floor fixes `GO-2026-6859`, a crash in `net/http`'s `MaxBytesReader`, which the HTTP server and `askiso mock` use to bound request bodies.
* **Release pages and docs you can check**: each release is titled `askiso <version>` with its pull requests and the SHA-256 of every download, the README verifies the Sigstore bundle releases actually ship, and every generated message in the catalogue validates again, including `head.001.001.01`.
